# RuralEstate

## 1. Описание системы

RuralEstate — это информационная система для оценки стоимости и привлекательности жилых домов и земельных участков в сельской местности. Основными пользователями системы являются покупатели, оценщики недвижимости и администраторы. Покупатели могут искать объекты, просматривать их характеристики, сравнивать стоимость и изучать показатели привлекательности. Оценщики добавляют информацию об объектах, рассчитывают их примерную стоимость и формируют отчёты об оценке. Система учитывает площадь объекта, состояние здания, характеристики земельного участка и доступность инфраструктуры. На основе этих данных формируются оценка привлекательности и рекомендации для потенциальных покупателей. Система помогает сравнивать объекты по единым критериям и принимать более обоснованные решения о покупке.

## 2. Цель проекта

Разработать архитектуру клиент-серверного приложения, которое позволяет хранить сведения о сельской недвижимости, рассчитывать её ориентировочную стоимость и оценивать привлекательность объектов.

## 3. Роли пользователей

- **Покупатель:** ищет недвижимость, просматривает характеристики, сравнивает объекты и добавляет их в избранное.
- **Оценщик:** добавляет сведения об объектах, рассчитывает стоимость, оценивает привлекательность и формирует отчёты.
- **Администратор:** управляет пользователями и проверяет корректность информации об объектах.

## 4. Основные функциональные возможности

- Регистрация и авторизация пользователей.
- Поиск и фильтрация объектов недвижимости.
- Просмотр характеристик домов и земельных участков.
- Сравнение нескольких объектов.
- Расчёт ориентировочной стоимости недвижимости.
- Оценка привлекательности с учётом инфраструктуры.
- Добавление объектов в избранное.
- Формирование отчётов об оценке.
- Управление пользователями и проверка данных.

## 5. Технологический стек

- **Frontend:** React.
- **Backend:** NestJS.
- **База данных:** PostgreSQL.
- **Протокол взаимодействия:** HTTPS.
- **Формат обмена данными:** JSON.
- **Инструмент проектирования архитектуры:** draw.io.

## 6. Архитектурный подход

Система использует трёхуровневую клиент-серверную архитектуру. Клиентский уровень отвечает за пользовательский интерфейс. Серверный уровень обрабатывает запросы, проверяет права доступа и выполняет бизнес-логику. Уровень данных хранит сведения о пользователях, объектах недвижимости, результатах оценки и отчётах. Клиент не обращается к базе данных напрямую: все операции выполняются через серверное API.
